# Data Model: Static Romantic Journey Website

## Entities

### Slide
- `id`: string
- `type`: "hero" | "counter" | "journey-photo" | "what-i-love" | "our-plans" | "final-message"
- `title`: string
- `subtitle?`: string
- `caption?`: string
- `message?`: string
- `image`: string
- `desktopImage?`: string
- `mobileImage?`: string
- `photo?`: string
- `items?`: Array<{ title: string; description: string; icon?: string }> 
- `referenceImageDesktop?`: string
- `referenceImageMobile?`: string

### RelationshipCounter
- `startDate`: string (fixed ISO or local date string)
- `years`: number
- `months`: number
- `days`: number
- `hours`: number
- `minutes`: number
- `seconds`: number

### NavigationState
- `currentIndex`: number
- `totalSlides`: number
- `canGoPrevious`: boolean
- `canGoNext`: boolean
- `loop`: boolean

### AudioState
- `isPlaying`: boolean
- `autoplayAttempted`: boolean
- `requiresInteraction`: boolean
- `source`: string

## Validation rules
- `currentIndex` must be between `0` and `totalSlides - 1`.
- `years`, `months`, `days`, `hours`, `minutes`, `seconds` must never be negative.
- `startDate` must be fixed to `2026-01-14T20:00:00` local time.
- Slide collection must contain exactly one `hero`, one `counter`, one `what-i-love`, one `our-plans`, one `final-message`, and exactly seven `journey-photo` slides.
- All image and audio references must resolve to local files under `apps/landing/public/assets/`.

## Relationships
- `RomanticJourney` orchestrates `Slide[]`, `NavigationState`, and `AudioState`.
- `CounterSlide` consumes `RelationshipCounter` values generated by `relationshipTimer.ts`.
- `BackgroundMusic` owns `AudioState` and playback lifecycle.
